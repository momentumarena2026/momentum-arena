LETTER SIGNING IMAGES — used on ALL generated letters (NDA + Offer Letter)
==========================================================================

Files here are read SERVER-SIDE only when a letter PDF is generated. They are
NOT under /public and are therefore never downloadable from the website — this
protects the signature + company stamp from being copied for forgery.

Keep these filenames EXACTLY:

  1. signature.png   — Nakul Varshney's signature. Transparent-background PNG.
  2. stamp.png       — Company stamp / seal.       Transparent-background PNG.

On every letter the signature is drawn OVERLAPPING on top of the stamp, above
"Nakul Varshney — Authorised Signatory". If a file is missing, the letter still
generates (a signature line + printed name are shown instead).
