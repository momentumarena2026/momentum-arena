**Scorer console redesign + rules (71057cd→7c802ad, 2026-07-29, dev):** pinned rounded scoreboard card + thumb-first pad on both platforms. Two on-field rules now enforced from the fold, so web and app never re-derive them: `dismissed[]` (a batter who's out can't be picked to bat again) and `spells[]` (per-bowler balls) checked against the **new `Tournament.maxOversPerBowler` column** — cricket-only, 0 = no limit, set in the admin wizard. **This column needs `prisma db push` before promoting to main** (already pushed to the staging DB). Gotchas learned: RN clips large digits without an explicit `lineHeight`, and needs `textAlign` + `includeFontPadding:false` to centre them; the console polls every 5s, so its rate limiter must charge the budget only on a *failed* lookup or real scorers get locked out after five minutes (a venue is one NAT'd IP). Also: React Navigation v7 `navigate()` doesn't bubble from three navigators deep — the app's "Open scorer" was a silent dead tap until the console was registered on the admin MoreStack itself.

**Scoring-rule enforcement (9b9ef80, 2026-07-29, dev):** the live API used to validate only an event's SHAPE (kind allowed for the sport, ids on a roster), never whether it made sense given the log so far — so runs could be logged with nobody on strike and nobody bowling, and the event was appended even when the fold ignored it. `validateLiveEvent` in lib/tournament-live now re-folds the log on every event and checks state preconditions for all three sports (cricket crease/side/dismissed/quota/consecutive-overs/innings; football team+scorer+assist+cards+clock; pickleball side+game-end). **It has to live server-side: the scorer code IS the credential, so a disabled button is a courtesy, not a control** — same reasoning as the authZ class-bug in [[mobile-admin-authz-audit]]. Pickleball deliberately does NOT enforce "11, win by 2" (target isn't configurable; venues play 15 and 21). Verifying app work needs the Android emulator route below, not screenshot-reading.

**Verifying the mobile app locally (learned the hard way 2026-07-29):** there IS a `Pixel_10_Pro_XL` AVD. `JAVA_HOME=/Applications/Android Studio.app/Contents/jbr/Contents/Home`, `ANDROID_HOME=~/Library/Android/sdk`, then `./gradlew app:installDebug -PversionName=1.0.0 -PversionCode=29999999` from apps/mobile/android — **the versionCode must exceed the dev channel's `minSupportedBuild` (29707705 as of now) or the app hard-gates on "Update Required"**; the check is `/api/app/version-check?platform=android&channel=development&build=…`. Debug builds pull JS from Metro, so a stale APK just needs the JS reloaded, but a native/RN version mismatch shows as "Cannot read property 'EventEmitter' of undefined" and needs a real rebuild. The scorer console sits behind login on the Account screen; to reach it without authenticating, temporarily set `initialRouteName="ScorerConsole"` + `initialParams={{code}}` on the RootNavigator stack and revert before committing.
