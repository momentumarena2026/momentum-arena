# Archive — point-in-time working notes

These are the assistant's running notes from earlier sessions, ported out
of a machine-local memory store so they travel with the repository instead
of with one laptop or one account.

**Treat them as history, not as truth.** Each was accurate on the day it
was written and several have since been overtaken — a note saying
something is "pending" or "in flight" usually means it shipped weeks ago.
`INDEX.md` is the original one-line-per-note index.

The curated, maintained picture is `docs/PROJECT-CONTEXT.md`. When the two
disagree, PROJECT-CONTEXT wins; when PROJECT-CONTEXT is silent, these are
worth reading for the *reasoning* behind a decision, which is the part that
does not survive in a diff.

Anything here naming a file, flag or function was true when written.
Confirm it still exists before relying on it.
